# Pong 22#$ — طراحی و ساختار

## جهت بصری
- **حرکت طراحی:** آرکید نئونی مینیمال با حس پنل کنترل علمی‌تخیلی.
- **اصل‌ها:** زمین خوانا، کنتراست بالا، عناصر تزئینی محدود و بازخورد مستقیم برای برخورد/امتیاز.
- **فلسفه رنگ:** زمینه‌ی سرمه‌ای عمیق برای تمرکز، فیروزه‌ای برای بازیکن، صورتی برای رایانه و طلایی برای امتیاز.
- **پارادایم چیدمان:** نوار وضعیت بالایی، زمین مستقل در مرکز و کنترل‌های گوشه‌ای؛ بدون کارت‌های متراکم.
- **نشانه‌ها:** خط وسط نقطه‌چین، درخشش توپ و دو اسکین متفاوت برای پدل چپ.

## معماری
- `scripts/main.gd`: مالک حلقه‌ی بازی، ورودی، حرکت پدل‌ها، توپ، برخورد، امتیاز و UI.
- `scenes/main.tscn`: صحنه‌ی اصلی با یک کنترل تمام‌صفحه.
- `assets/skins/user_green_armor.png`: اسکین چهره‌محور تولیدشده از تصویر کاربر با پس‌زمینه شفاف.
- `project.godot`: نمایش 1280×720 با stretch mode=`keep` برای خروجی وب.
